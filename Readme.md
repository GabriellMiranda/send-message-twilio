# Send Message Twilio

Este é um projeto Django para enviar mensagens utilizando a API do Twilio.

## Requisitos

Antes de rodar o projeto, verifique se você possui os seguintes pré-requisitos:

- Python 3.8 ou superior
- Pip (gerenciador de pacotes do Python)
- Virtualenv (opcional, mas recomendado)
- Conta no Twilio (para obter o SID da conta, token de autenticação e número de telefone)
